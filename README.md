# Feierabend · Cervejaria Artesanal

Site de uma cervejaria artesanal **fictícia**, feito como projeto de portfólio para mostrar o que dá para entregar a um pequeno negócio: um site rápido, bonito e que já recebe pedidos.

**[Ver o site no ar](https://davi-webdev.github.io/site-cervejaria/)**

![Prévia do site da Feierabend](midia/previa.jpg)

## O que o site faz

- **Abertura animada** com um copo de chope enchendo
- **Pergunta de idade (18+)** antes de entrar, como todo site de bebida
- **Quatro cenas de vídeo** que contam a história da cerveja conforme a rolagem: do campo de cevada ao copo
- **Cardápio em abas:** três cervejas (Remanso, Cheia e Foz), itens pra levar (growler, kit, caixa e barril) e petiscos
- **Carrinho** que monta o pedido com quantidades e total, e abre pronto no WhatsApp
- **Horário automático:** o site mostra sozinho se a casa está aberta ou fechada agora
- **Agenda da semana** com a programação de cada dia
- Feito pensando primeiro no **celular**, que é onde o cliente realmente abre o site

## Tecnologias

- HTML, CSS e JavaScript puro, sem framework
- [GSAP](https://gsap.com/) com ScrollTrigger para as animações de rolagem
- Hospedado no GitHub Pages

## Como rodar no seu computador

Não precisa instalar nada. Baixe o repositório e abra o `index.html` no navegador. As animações carregam o GSAP pela internet, então é bom estar conectado.

## Aviso

A Feierabend **não existe**. A marca, as cervejas, os preços e o número de WhatsApp (5500000000000) são fictícios, criados só para este portfólio.

Quer um site assim para o seu negócio? Fale comigo pelo [GitHub](https://github.com/davi-webdev).
